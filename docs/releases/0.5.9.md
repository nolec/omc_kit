# OMC 0.5.9 — 리뷰 승인 범위 대조

사용자가 요청한 패치 릴리스다. 승인하려는 파일 목록과 실제 후보가 다르면 승인 기록 생성을 차단한다. 기존 기록과 stale 검증은 유지한다. 대시보드 현재 요약과 과거 이력을 분리하고 C3 상태 및0.5.8 사용자 이해 검증 조건을 정리했다.

## 사용법 변경

`record-review`의 새 기록 생성에는 `--expected-path <저장소 상대 파일>`를 파일마다 반복 지정해야 한다. 내부 함수 호출도 `expected_paths`가 필요하다. 생략한 기존 호출은 `review_scope_required`로 차단되므로 호출자를 갱신해야 한다. 이 경로는 기존 호출에 영향을 주는 계약 강화이며, 계약 변경 없는 일반 패치로 해석하면 안 된다. 이번에는 사용자가 지정한 패치 버전으로 배포하고 이 예외를 명시한다. 과거 receipt의 스키마나 내용을 바꾸지 않는다.

## 검증과 반영 경계

관련146개 회귀 통과 및 구현·문서 격리 리뷰 완료. 릴리스 전체 품질 게이트 결과와11개 사용처 설치 감사는 실제 실행 후 별도 기록한다. 이 파일만으로 게이트·설치 성공을 주장하지 않는다. 관측 재등록·재개는 하지 않으며 ai-cs 사용자 중단을 보존한다. 실제 생산성·경쟁 우위는 미입증이다.
