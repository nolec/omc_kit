# OMC 0.6.2 — 출하 준비와 사용자 안내·증거 연결 보완

`9333246`의 구현·문서를 기반으로 준비하는 호환 패치 릴리스다.

## 포함된 수정

- `current_delivery_v1`은 현재 기능·설치·실제 광고 빌드를 필수 검증하고, 외부 과거 입력 2개와 RED 표식 1개는 별도로 분리한다. 과거 자료 미확보·미검증을 성공으로 바꾸지 않으며 실제 모듈 import 확인은 유지한다.

- 기계 판정 OMC_OUTPUT과 사용자용 한글 안내를 분리하고, 별도 기록의 원문·해시·세션 연결 및 기록 실패 시 차단을 유지한다.
- 동일 커밋 이관의 완료 판정을 구현 작업과 구분하며, 승인 범위·원래 검증·내용 일치·보존 증거가 확인된 경우에만 RED 요구를 제외한다.
- 출하 사전 점검에서 고정 기준·후보·변경 목록을 확인한다. 복제용 원격과 계약 기준 참조를 분리하고 인덱스 플래그에 숨은 파일 변경도 HEAD와 직접 대조한다.
- 새 clone에 Git 추적 `.omc`를 제한적으로 재사용한다. 메타데이터 목록을 설정 생성 직전에 재확인하며 기존 대상·링크·교체·설정 덮어쓰기는 계속 차단한다.
- 검수 실행기·감독의 오류 원문, 시간 경계, 종료 확인과 실패 결과 소비·증거 보관을 보완한다.

## 검증과 적용 경계

릴리스 메타데이터의 버전 검사와 최종 후보의 전체 출하 검사는 별개다.
최종 후보 SHA·설정 해시·검사 결과·생략 목록과 정상 사용처 11개 설치·엄격 감사 결과는
실제 실행 기록으로 확인한다. 이 문서만으로 전체 검사 통과나 설치 완료를 주장하지 않는다.

현행 기준은 새 설정·리뷰·고정 후보에 연결해야 한다. 과거 후보의 생략 예외 3개와 승인 기록은 보존하며 현행 검사에 자동 승계하지 않는다.
실제 광고 빌드는 필수이며, 다른 실패·오류·미승인 생략은 차단한다.
타입·린트 독립 명령은 현 프로젝트 품질 계약에 없다.

원격 push·태그·GitHub release는 기존 로컬 패치 릴리스 범위에 포함하지 않는다.
사용처의 수정된 관리 파일·업무 파일·기존 관찰 설정을 임의로 덮어쓰지 않으며,
marketing-project는 기존 제외를 유지한다. 실제 홈 미검증과 비교 HOLD는 유지한다.
출하 검사나 재설치 성공을 실제 홈·Claude 비교·생산성 우위의 증명으로 확대하지 않는다.
