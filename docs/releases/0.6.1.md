# OMC 0.6.1 — 필수 검증 실행과 출하 검사 격리 보완

`904c58d`의 검증·증거 연결 보완을 포함하는 호환 패치 릴리스다.

## 포함된 수정

- 고정된 필수 검증 명령의 실행 결과와 증거를 연결하고, 비교 진입 시 실제 호출·성공 반환을 구분한다.
- 계약·설치 결과 검사를 임시 대상으로 격리해 실행 중인 작업 상태와 개발용 설치 파일에 대한 의존을 줄인다.
- 내부 격리 검사에서 불필요한 benchmark 플러그인의 Git 인덱스 캐시 갱신을 차단한다. 인덱스 원문 동일성 검사는 유지한다.
- 내부 검사 전후 인덱스 원문·해시·실행 대상·명령을 실행별로 보존한다. 실패·시간 초과와 임시 복제본 삭제 후에도 증거를 확인할 수 있다.

## 검증과 적용 경계

기준 코드 `904c58d`의 전체 출하 검사 1회는 4,790 passed, 3 skipped,
12 slow deselected로 통과했다. 생략 3개는 외부 과거 입력 검증 2개와 의도적 RED
표식 1개에 한정한 사용자 승인 예외이며, 통과로 집계하지 않는다. 실제 광고
빌드와 산출물 보존, 내부 인덱스 기록 5건의 전후 원문 동일성을 확인했다.

이 결과는 버전 메타데이터를 바꾸기 전 기준 코드의 검증이다. 최종 0.6.1 후보의
검증과 정상 사용처 11개 설치·엄격 감사 결과는 별도 실행 기록으로 확인한다.
타입·린트 독립 명령은 현 프로젝트 품질 계약에 없다.

원격 push·태그·GitHub release는 이번 로컬 패치 릴리스 범위에 없다.
기존 업무 파일·로컬 변경·관찰 설정은 보존하며 marketing-project는 기존 제외를
유지한다. 빌드와 출하 검사 통과는 실제 홈·Claude 재비교·생산성 우위의 증명이 아니다.
