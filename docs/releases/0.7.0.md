# OMC 0.7.0 — 단일 승인 V0와 완료·출력 기록 보완

## 포함 범위

- Codex·Python/pytest·기존 파일 수정의 선택형 단일 승인 V0. 승인 범위와 예산 안에서 실제 RED→구현→검증→독립 검사→리뷰→최대2회 수정→격리 후보를 연결한다. 원본 반영·PR·배포는 포함하지 않는다.
- 전역 설정을 보존하는 명시 Codex 모델, 완료 작업 소유권과 재진입 보완.
- 만료된 완료 작업의 명시적 정리를 `EXPIRED_COMMITTED`로 구분한다. 소유 세션·완료 영수증과 기존 세션 초기화 인식을 보존하고, 중단 복구 시 새 pending 기록·증거 변경·알 수 없는 보관 상태를 차단한다. 격리 소비자에서 설치 충돌 및 과거 보관 기록 보존을 검증했다.
- 대기 완료 기록 없음과 손상·불일치·읽기 오류 구분, 커밋 성공과 post-commit 기록 실패 안내 분리.
- 경고부 계획 판정 지원, plan/critique-plan의 제한된 실패 초안 설명과 표시 직전 무결성 재검증. 종료2·기존 manifest·승인/검증 기한·완료 gate를 유지한다.
- task의 단순 운영 기록 예외 설명을 공통 기계 계약 블록 밖으로 옮겨 기존 문구 정합성 실패를 정리한다. 예외 의미와 테스트 조건은 유지한다.

## 검증·배포 경계

구현별 관련 회귀와 격리 코드 리뷰를 보존한다. 이 기록은 버전·문서·생성 파일을 포함한 최종 릴리스 후보의 전체 품질 검사 통과를 대신하지 않는다. 최종 전체 검사·재설치 결과는 이번 실행 기록으로 확인하며, 이 문서는 준비 시점에는 검사/설치 완료를 주장하지 않는다.

다중 커밋 전체 연결·명시 기록 복구, 출력 재발행·과거 조회는 미구현이다. 실제 모델 준수·사용자 개입 감소·경쟁 우위는 미검증이다. 기존 비교 HOLD와 관찰 비활성을 유지한다.

사용처의 업무 파일·index·프로젝트 전용 설정을 보존하고 관리 파일 충돌은 자동 덮어쓰지 않는다. 원격 push·태그·GitHub/registry 공개는 이 로컬 릴리스에 포함하지 않는다.
