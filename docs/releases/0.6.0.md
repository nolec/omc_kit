# OMC 0.6.0 — 필수 검증과 통제 광고 화면 판정

승인한 검증의 대상·방법·버전과 후보 스냅샷을 연결해 미실행·실패·증거 불일치를 완료로 보고하지 않도록 보완했다. 실제 실행을 인증하는 보안 장치나 모든 자유 응답을 차단하는 기능은 아니다.

## 포함된 변경

- `approve-checks`로 이미 받은 검증 기준 승인을 기록하고 CONTRACT와 같은 ID를 연결한다. `verification-template`의 초기 상태는 unrun이다.
- 승인 기준이 있는 작업의 RED는 `--evidence-file`로 새 실패 케이스·기존 실패·실제 출력·해시를 연결한다. 기준 없는 legacy 편집 의미는 유지하되 완료를 확정하지 않는다.
- 정상 내부 폴더 링크의 대상·내용·권한을 스냅샷에 포함한다. 외부·순환·검사 제외 링크는 보류한다.
- 광고 비교의 선택형 준비 검사에서 동결 입력·제외 규칙·실제 홈의 이미지와 카드 전환을 확인한다. 엄격 수집기는 작업 범위와 최종 보고를 따로 판정한다.
- 선택형 통제 화면 검사는 실제 Chromium 캡처의 이미지 표식·정의한 직선 테두리 구간을 판정한다. 필수 검사로 승인하면 누락·실패·unknown은 전체 비교 통과를 막는다.

## 호환성과 실행 경계

새 선택형 CLI와 승인 검증 계약을 포함하므로 minor 버전으로 배포한다. 승인 기준이 있는 작업은 문서의 RED JSON과 검증 템플릿 절차를 따라야 한다. 기존 기록과 실패 원문은 소급 수정하지 않는다.

화면 검사에는 별도로 준비한 Node.js·Playwright·Chromium·Pillow가 필요하며 자동 설치하지 않는다. `docs/visual-controlled-check.md`와 `docs/workflow-preflight.md`를 따른다. 통제 화면 성공은 실제 로그인 홈·외부 이벤트 전송·일반 생산성·경쟁 우위의 증명이 아니다.
