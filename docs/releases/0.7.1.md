# OMC 0.7.1 — 검증 준비·만료 재개·문서 커밋 연결

- 검증 부산물을 업무 폴더 밖에 격리하고 pytest 설정·경로 충돌을 실행 전에 확인한다.
- plan/critique-plan 출력 기록의 새 실행 문맥과 읽기 전용 관찰 경로를 보완한다. 판정 본문의 임의 표현으로 인한 body_judgment_invalid 전체 해결을 주장하지 않는다.
- 동일 작업의 analysis/code_review 세션에서 구현 소유 이력을 검증해 제한 재개 제안을 만들고, 손상된 이력·권한 슬롯은 명시적으로 거부한다.
- 만료 작업을 EXPIRED_UNFINISHED로 보존·분리한 뒤, 기존 스테이징·index 플래그를 보존하는 문서 전용 커밋 경로를 연결한다. 재개 grant는 커밋·출하 권한을 부여하지 않는다.

구현별 격리 검증과 리뷰를 통합한 최종 후보다. 전체 품질 검사는 승인된 설정으로 1회, 최대 60분 실행하며 실패·시간 초과 시 설치하지 않는다. 통과 후 기존 12곳에 재설치하고 업무 파일·Git index·HEAD와 strict 설치 감사를 확인한다. 설치 충돌은 백업만으로 임의 덮어쓰지 않는다.

이 문서는 릴리스 준비 시점의 범위와 검증 계약이다. 실제 전체 검사·설치 결과는 이번 실행 원문으로 별도 확인한다. 원격 push·태그·공개 릴리스는 포함하지 않는다. 실제 모델 준수·개입 감소·경쟁 우위와 기존 비교 HOLD는 미검증으로 유지한다.
