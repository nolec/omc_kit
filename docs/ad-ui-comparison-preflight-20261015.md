# 광고 UI 비교 사전 준비 점검 · 2026-10-15

## 결과: 재비교 준비 미완료

유료 구현 모델을 호출하지 않았고 재비교를 시작하지 않았다. 제품·가드·원본 서버·원본 환경 설정을 변경하지 않았다. 이전 승인된 비교 기록5개 파일은 보존했다.

| 조건 | 확인 결과 |
|---|---|
| R1 실제 홈·광고 검수 | 부분 확인. 재확인에서 홈 본문과 상단 배너(이미지 로드 완료) 표시. card-large0개·banner-small1개로 카드 광고 검수는 아직 불가 |
| R2 절차 진입 준비 | 설치 명령 파일과 이전 native init 등록 목록에서 `/task`, `/oh-my-claudecode:execute` 확인. 호출 방식만 준비했으며 새 명령 실행·절차 준수는 미검증 |
| R3 작업 결속 | pair/run ID, 요청·지침 해시, 기준 코드, native session, 이벤트 순서의 기록 명세 작성 |
| R4 동일 완료 기준 | 실제 홈과6개 통제 variant를 분리하고 테두리·전환·클릭·추적·숨김 기준을 초안에 명시. 실제 서비스 링크·소재가 확인되기 전 브라우저 절차는 최종 동결하지 않음 |
| R5 측정 | 준비·모델·검수 시간 분리, 재작업1회 정의, 사용자 개입과 로그인 준비 개입 분리, 판정 불가 기준 작성 |

R2~R5는 준비 명세이며 실제 작업 성공이나 절차 준수의 통과 기록이 아니다. R1 미통과와 실제 서비스 관측 조건 미확정으로 실행 명세는 `DRAFT_NOT_RUN`, 전체는 `NOT_READY`다.

## 환경 확인 경위

기존 로컬 개발 환경 파일을 임시 기준 서버 프로세스의 메모리로 읽었다. 환경값을 출력하거나 증거 파일로 복사하지 않았다. 별도 localhost:3011 서버에서 기존 iron-session 설정 오류가 사라졌고 로그인 화면이 표시됐다. 사용자가 ‘로그인 완료’라고 응답한 뒤 실제 홈 경로와 메뉴 렌더링을 확인했다.

하지만 홈 본문과 광고 컴포넌트가 표시되지 않았다. 콘솔에서400·404와 AxiosError 및 원격 모듈 관련 오류 유형을 관측했다. 특정 실패 endpoint와 홈 미표시의 인과관계는 확정하지 않았다. 따라서 로그인 성공·서버 시작·메뉴 노출을 실제 업무 검수 준비 완료로 승격하지 않는다. API 응답 조작·DOM 삽입·제품 수정으로 이를 우회하지 않았다.

기준 복사본의 추적 파일은 변경되지 않았다. 원본3000 서버는 그대로 두고3011 검수 서버만 사용했다. 이 실행은 기존 실패를 재현하거나 수정하는 제품 검증이 아니라 준비 확인이다.

## 다음 실행에서 고정할 경계

OMC는 명시적 `/task`, 비교군은 명시적 `/oh-my-claudecode:execute`로 시작한다. 승인된 요청의 세션 등록은 준비 단계로 별도 기록하되 CONTRACT·RED를 미리 완료 처리하지 않는다. 현재 작업에 연결된 명령 소비·실패 테스트·수정·재검증 기록이 있어야 절차 적용을 판정한다. 비교군에 OMC 내부 체크포인트를 강요하지 않으며 양쪽의 최종 사용 가능 여부·외부 검증 조건은 동일하게 둔다.

이전 모델 실행은 OMC 선행이었으므로 다음 초안은 비교군 선행으로 두되, 한 쌍으로 인과적 우위를 주장하지 않는다. 환경 준비·로그인·검수 비용은 모델 시간과 분리한다. 전환은 단위 fake clock과3~4초 통제 화면 관측을 구분하며 실제 홈의 소재 수에 따른 관측 가능 여부를 사전에 기록한다.

## 재확인 · 2026-10-15

사용자의 재확인 요청 시 홈 본문과 상단 배너1개가 표시됐고 배너 이미지 로드 완료를 확인했다. 이전 본문 미표시는 현재 해소됐으나 원인은 확정하지 않았다. 카드 광고는 DOM0개로 계속 미표시다. 기존400·404 관측을 현재 장애 원인으로 단정하지 않으며, 카드 소재 공급 여부와 미표시 원인도 미확정이다. 따라서 준비 상태는 여전히 NOT_READY이며 새 모델 실행은 하지 않았다. 이전 미표시 관측은 checks.json의 recheck_history에 보존했다. 최신 근거는 임시 경로의 runtime-recheck.json과 recheck-banner.jpg다.
