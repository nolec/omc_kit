# Codex 전용 OMC 정리

사용자는 Codex 스킬·공통 엔진 유지, Claude·Gemini·Cursor 지원 제거, 자동 훅 비활성화 유지를 선택했다.

## 접근과 범위

스킬만 남기면 공통 엔진도 제거되므로 선택하지 않는다. Codex 전용 배포·검사 계약을 만들고 다른 IDE의 구성·설치 분기를 제거한다. Codex용 `.agents/skills`, 공통 `scripts`, `prompts`, 호출 가능한 공통 훅 스크립트는 보존한다. 중복 Antigravity `.agent` 배포도 Codex 전용 배포에서 제외한다. `.agent` 기존 자료는 소유권을 확인한 OMC 생성물만 제거한다.

새 설치와 재설치에서도 Claude·Gemini·Cursor·Antigravity 구성을 생성하지 않는다. Codex 자동 훅과 Git 자동 훅은 활성화하지 않으며, 생성 지침도 세션 초기화나 훅 실행을 강제하지 않는다. 명시적으로 호출하는 공통 엔진·검증 가드는 유지한다. 사용하지 않는 IDE가 없다는 이유로 doctor가 설치 결함을 보고하지 않게 한다. 훅 비활성 상태와 엔진 작업 완료·승인 상태를 혼동하지 않는다.

## 보존 경계

기존 미커밋 변경, 기록 삭제 상태, 백업, 실패 원문, 테스트 fixture의 과거 계약은 보존한다. 실제 프로젝트 설치, storefront 변경, 복구, Git commit/push는 포함하지 않는다. 제품 코드·Git 원장·기존 정리 백업은 변경하지 않는다. 공통 엔진의 외부 모델 provider 지원과 과거 연구·벤치마크 자료는 이번 제거 범위가 아니다.

## 검증과 완료

격리된 임시 타깃에서 새 설치·재설치·doctor·명시 실행 경로를 검증한다. 다른 도구의 사용자 설정을 설치기가 삭제하거나 수정해서는 안 된다. 원본 kit에서 삭제하는 도구별 파일은 파일 목록을 먼저 고정하고 고유 내용과 메타데이터를 새 보존본에 저장한 뒤 제거한다. 디렉터리 이름만 보고 전체 삭제하지 않는다.

설치·배포·검사·문서 계약이 Codex 전용으로 일치하고 자동 훅이 꺼져 있으며, 관련 회귀 검사가 통과하면 완료다. 배포 기능 제거를 실제 프로젝트에 적용하는 설치 실행은 별도 작업이다.
