## 절차 적용 관찰

OMC의 SessionStart 문맥 주입은 관측됐다. 그러나 보존한 상위 실행 기록에는 task 명령 파일 읽기·명시적 task 호출·contract/red 가드 명령이 확인되지 않았다. 비교군은 `Skill: oh-my-claudecode:execute` 호출이 관측됐다. 하위 작업 전체의 행위를 부재로 단정하지 않으며, 설치 여부를 네이티브 절차 준수로 취급하지 않는다. 따라서 이번 실행은 설치 문맥을 둔 탐색 비교이며 새 완료 보고 지침을 실제 task 절차에서 검증한 결과가 아니다.

OMC 최종 본문에는 브라우저 미검증이 적혀 있지만 제목은 ‘완료 보고’다. 비교군은 ‘구현 완료’와 브라우저 미검증을 함께 보고했다. 전체 완료와 구현 완료를 사용자가 구분하는지는 별도 확인하지 않았다. 두 보고를 새 기계 출력 계약 준수로 집계하지 않는다.

## 검증 경계와 재작업

OMC는 자체 검사에서 border 단언 문자열3건 실패를 수정했다. 비교군은 여분 빈 줄 린트 오류1건을 수정했다. 두 도구 모두 기준 코드를 별도로 검사해 기존 실패를 확인했다. 이는 도구 내부 재작업 사례이며 정확한 재작업 시간은 별도 계측하지 않았다.
