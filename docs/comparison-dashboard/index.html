비정수 입력은 traceback 없이 stderr에 error: integer required를 출력하고 exit 2로 종료하라. 정수 합산 동작은 유지하라.

S2 · JSON 출력 추가

--format json 옵션에서 {"sum": 5} 형태의 유효 JSON을 출력하라. 기본 텍스트 합산과 입력 오류 계약은 보존하라.

S3 · 첫 단계 종료 후 중단·재개

S1 수정 완료 후 S2 직전에 실행을 중단한다. 동일 요청으로 재개해 S1을 유지하고 S2를 완료하라. 요청이 바뀌면 과거 완료 상태를 현재 요청의 완료 증거로 쓰지 마라.
