# 광고 Ad 유지보수 공통 과제

Figma: https://www.figma.com/design/aUwDN009sASspXFDrXWwdP/?node-id=5437-49209
기준 커밋: 34078b6f923587b03c0fbac3d7a5a3c4bf5c0cfc

## 확정 요청
광고 구간에 1px solid rgba(0,0,0,0.1) 테두리와 0px 1px 2px 0px rgba(0,0,0,0.05) 그림자를 적용한다. 기존 공통 토큰을 활용한다. 카드 광고 이전/다음 화살표를 제거하고 기존 3초 자동 전환을 유지한다.

## 확인할 경계
Ad의 6개 variant와 실제 호출 위치를 조사한다. '다른 광고 구간에도 동일 적용'의 구체적 범위를 설명하고, banner-landing처럼 별도 레이아웃인 경우 근거 없이 예외 처리하지 않는다. 이미지 광고의 테두리가 가려지지 않고 그림자가 잘리지 않아야 한다.

## 회귀와 완료
광고 0개/1개/여러 개, 자동 전환과 unmount 정리, 광고 클릭/추적/오늘 하루 숨김을 확인한다. 변경 범위에 맞는 테스트와 프로젝트 검사 결과를 남긴다. 실제 호출 위치에서 브라우저로 디자인과 대조한다. 미실행 검증은 통과로 쓰지 않는다. API/광고 소재 교체, 무관한 화면 변경, push/PR/배포는 포함하지 않는다.

## 비교 기록
동일 모델/버전/권한/입력 디자인/실행 예산을 사전 확정한다. 시작/종료 시간, 환경 준비 시간, 사용자 질문/개입, 수정 반복, 최종 검증을 별도로 기록한다. 도구 이름을 가린 결과를 바로 사용 가능/수정 필요/실패로 평가한다. 이 명세 준비 시간은 구현 시간에 포함하지 않는다.
