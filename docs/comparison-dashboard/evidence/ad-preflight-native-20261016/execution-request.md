# 공통 광고 유지보수 비교 실행 요청
사용자가 같은 범위와 완료 기준을 승인했습니다. task.md, design-reference.md, design-section.png를 읽고 현재 작업 복사본에서 광고 Ad 유지보수를 수행하세요. 기존 컴포넌트·토큰·규칙을 따르세요.

포함: 이미지 위에서도 보이는 테두리·그림자, 6개 variant와 실제 사용처 조사, 카드 화살표 제거, 기존 3초 자동 전환·클릭·추적·오늘 하루 숨김 보존. 모델 실행 전 Home.tsx에 같은 검수용 광고2개를 준비했습니다. 준비 자료를 수정하거나 Figma 소재로 실제 동적 광고를 고정하지 마세요.

필수 검증은 common-required-checks.json의 tests, lint, browser-controlled, browser-home 네 항목입니다. 항목을 축소·교체하지 마세요. 테스트 baseline은 baseline-failures.json(41통과, 기존 추적4실패)입니다. 기존4실패의 이름·진단이 같으면 신규 실패와 구분하되 미해결임을 보고하세요. 코드 승인·통제 화면·로그인된 실제 홈은 별개의 사실입니다. 화면에 접근하지 못하거나 확인이 안 되면 미실행/불일치로 남기고 완료했다고 주장하지 마세요.

## 실제 브라우저 도구
작업 폴더에서 아래 공통 명령으로 본인 브라우저만 직접 제어합니다. 로그인은 조정자가 준비하고 광고2개 표시까지 사전 점검합니다.
- node ../browser.cjs snapshot : 현재 URL·본문·실제 스크린샷 경로 반환. 반환된 PNG를 Read로 열어 눈으로 확인하세요.
- node ../browser.cjs evaluate '<자바스크립트 표현식>' : 실제 페이지 DOM·computed style·이미지 상태 조회. 쿠키·저장된 인증정보 접근 금지.
- node ../browser.cjs goto /sixshoptest01 : 실제 서비스 홈.
- node ../browser.cjs wait 3700 : 시간차 관찰. 스크린샷·DOM 표본으로 자동 전환 확인.
- node ../browser.cjs reload : 현재 후보 코드로 새로고침.
- node ../build-controlled.cjs : 본인 현재 Ad 코드를 통제6종 페이지로 빌드.
- node ../browser.cjs goto /omc-ad-validation/index.html : 통제6종 페이지(실제 홈 증거가 아님).
도구가 정상 실행됐다는 사실만으로 디자인 통과를 추정하지 마세요. 변경 후 현재 후보에서 두 화면 모두 직접 확인해야 합니다. 빌드 산출물은 Git ignored이며 구현 증거 snapshot 자체가 아닙니다.

프로젝트 AGENTS.md·CLAUDE.md를 따르고 도구의 정상 실행 절차를 사용하세요. 이미 승인된 범위는 다시 묻지 마세요. 수정 범위는 libs/sellerhub-store/src/lib/components/Ad/ 아래 구현·테스트입니다. 필요하면 해당 폴더 안 기존 스타일·상수를 활용하세요. Home.tsx·공통 도구·기준 파일·다른 범위는 수정하지 마세요. 실제 외부 광고 클릭·유료/업무 데이터 변경은 하지 말고, 클릭/숨김의 보존은 테스트·읽기 전용 관찰 범위를 구분해 보고하세요.

다른 복사본·다른 실행 결과 열람 금지. 본인 작업 폴더와 이 부모 폴더의 task/디자인/공통 검증 기준·baseline 진단·브라우저 도구만 사용할 수 있습니다. 패키지 설치·의존성/lockfile 수정·전역 설정·원본 서비스 수정·커밋/push/PR/배포·하위 모델 호출은 금지합니다. .omc 안 기록 작성과 본인 변경 파일 스테이징은 허용합니다. 브라우저/서버 준비 시간은 모델 시간에서 제외합니다.

최종 보고는 한글로 구현 상태·변경 파일·실제 수행 검증·미검증 및 기존 실패·다음 행동을 짧게 제시하세요. OMC 전용 기계 계약은 해당 도구에만 적용하며 경쟁 도구에 강요하지 않습니다.
