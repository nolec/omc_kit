# 공통 입력: 실제 Ad 독립 화면

요구 파일은 아래의 일반 파일 하나입니다. 디렉터리 대신 이 파일을 읽으세요.

- 후보 기준 상대 경로: `.omc/visual-requirement.json`
- 실제 절대 경로: `{{CANDIDATE_ROOT}}/.omc/visual-requirement.json`
- 고정 SHA256: `{{REQUIREMENT_SHA256}}`

manifest 생성 절차도 같은 파일을 참조합니다. 존재·경로·해시가 다르면 준비 실패로
보고하며 별칭·복사본을 만들거나 기준을 바꾸지 않습니다. 도구별 승인·실행 지시는
별도 부록으로 제공하며 공통 요구 파일에 특정 도구의 세션 정보를 추가하지 않습니다.

## 시간표

300초 경과만으로 중단하지 않습니다. 300초는 진행 확인점이며 추가 지시나 시간 연장의
근거가 아닙니다. 누적 목표는 조사·신규 RED·소스/테스트 수정 종료 900초, 최종 7개
검증 1680초, 완료 기록·보고 1740초, 정상 종료 1760초, 자식 정리 1772초, 최종 기록 1800초입니다.
900초 이후 수정은 계약 위반으로 기록합니다. 이 문서는 편집을 물리적으로 차단하지
않으며 성공 시간을 보장하지 않습니다.

전체 1800초에 감독 사전처리·실행·회수를 포함할 실제 E0·절대 마감·timeout 인자는
공개 감독의 origin-monotonic·deadline-monotonic으로 같은 시계에 연결합니다. 실행 전에 별도 계획으로 실제 값과 버전을 고정해야 합니다. 준비·중간 정리·최종 기록을 포함한 전체 상한은
7200초이며 기존 정리 기한을 늘리지 않습니다. 실제 홈은 NOT_VERIFIED로 남깁니다.

이 템플릿 작성·검증은 실제 비교 실행 승인이 아닙니다.

## 종료·증거 계약

전체 마감은 E0+1800초이며 사전처리는 E0+30초까지다. 중단 시 정리 마감은 min(중단 시각+12초,E0+1772초)다. worker 응답·소유 그룹 종료·출력 회수·wait가 이 예산을 공유하며 기한 뒤의 그룹 부재를 소급 성공으로 바꾸지 않는다.

7개 명령 제한 합계750초와 화면 다시 로드·manifest 생성·결과 연결의 보조30초를 900→1680초 구간에 예약한다. 소요 시간 보장이 아니며 초과·미실행을 통과로 표시하지 않는다. 마지막 수정·7검증·완료 기록의 관측 시각과 최종 후보를 연결하며 파일mtime만으로 편집 시각을 증명하지 않는다. 단계 증거가 없으면 프로세스 정상 종료와 별도로 unknown이다.

감시 부모까지 SIGKILL되거나 저장 장치가 실패하면 기록·정리를 보장하지 않는다. 외부 호출자는 해당 run_id의 result와seal이 없거나 손상·지연됐으면 미확정으로 남긴다. 셸 종료 코드는 Claude 자체 종료 코드가 아니다.
