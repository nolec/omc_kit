### 미검증 및 기존 실패

- **클릭 추적·오늘 하루 숨김 통합**: 실제 외부 광고 클릭 금지 조건으로 읽기 전용 관찰에 그침. 테스트 코드는 변경 없이 41통과로 보존됨.
- **기존 4실패(미해결)**: `tracks each Catalog creative impression once…`, `tracks the same Catalog creative again…`, `tracks linked Catalog slide clicks…`, `tracks each active Catalog creative impression only once` — baseline과 동일 이름·진단이며 이번 구현과 무관.
