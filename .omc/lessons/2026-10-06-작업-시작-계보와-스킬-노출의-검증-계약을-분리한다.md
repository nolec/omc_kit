# 작업 시작 계보와 스킬 노출의 검증 계약을 분리한다
날짜: 2026-10-06
태그: cohort,lineage,scope,regression

## 증상
일반 제목의 구현 시작을 참조한 스킬 세션이 session_invalid로 관찰 전체 집계를 차단했다

## 원인
계보 시작 검증에 스킬 제목 제한을 함께 적용했다

## 적용된 규칙
계보 근거는 확정 상태 작업 ID 시작 시각 work class를 검증하고 스킬 제목 제한은 스킬 노출에만 적용한다. 과거 실패를 성공으로 덮어쓰지 않는다
